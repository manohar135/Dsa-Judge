You are given an array $a_1, a_2, \dots, a_n$ and an integer $k$.

Count the number of pairs of indices $(i, j)$ with $1 \le i < j \le n$ such that $a_i + a_j = k$.

### Input
The first line contains two integers $n$ and $k$.
The second line contains $n$ integers $a_1, \dots, a_n$.

### Output
Print a single integer — the number of such pairs.

### Constraints
- $1 \le n \le 2 \cdot 10^5$
- $-10^9 \le a_i, k \le 10^9$
